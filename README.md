## ✨ 功能特点

- **高速扩展**：1× USB3.0 Type-B 上行端口 → 4× USB3.0 Type-A 下行端口，理论速率 **5 Gbps**
- **即插即用**：纯硬件方案，**无需固件烧录**，上电自动识别为通用 SuperSpeed USB 集线器
- **双方案兼容**：同时支持 **VL812**（威锋电子，台湾）与 **CH634X**（沁恒微，国产）两种主控，可根据供应链灵活选型
- **电源保护**：集成 **SY6280AAAC** 过流保护芯片，限制输出电流 ≤1A，防止主机端口过载
- **过压防护**：每路 USB 端口配备 **SMBJ5.0CA** TVS 二极管，抑制静电与浪涌
- **状态可视**：4/5 路 RGB LED 独立指示各下行端口工作状态，插入亮起 / 弹出熄灭
- **全贴片设计**：0402/0603/0805 主流封装，适合 SMT 批量生产

## 🔧 核心器件选型说明

### 方案一：VL812（主推荐方案）

|    器件    |     型号    |        厂商       |     封装    | 选型理由                                         |
| :------: | :-------: | :-------------: | :-------: | :------------------------------------------- |
|  HUB 主控  | **VL812** | VIA Labs (威锋电子) |   QFN-76  | 成熟稳定的 USB3.0 HUB 方案，单芯片集成 1.2V/3.3V LDO，外围极简 |
|    晶振    |   25MHz   |    KDS (大真空)    |  SMD-3225 | VL812 官方推荐频率，±30 ppm 精度保证高速信号稳定性             |
| DC-DC 电感 |    10μH   |       顺翔诺       | 5.0×5.0mm | 为 VL812 内部 1.2V DC-DC 供电，饱和电流充足              |

### 方案二：CH634X（国产替代方案）

|    器件    |     型号     |      厂商     |     封装    | 选型理由                                           |
| :------: | :--------: | :---------: | :-------: | :--------------------------------------------- |
|  HUB 主控  | **CH634X** |  沁恒微 (WCH)  |   QFN-68  | 国产 USB3.0 HUB 芯片， Pin-to-Pin 兼容度高，成本优势明显，供应链安全 |
|    晶振    |    24MHz   | muRata (村田) |  SMD-3225 | CH634X 官方标称频率，负载电容 16pF 匹配                     |
| DC-DC 电感 |    2.2μH   |    muRata   | 4.4×4.2mm | CH634X 内部 Buck 转换器推荐感值，纹波更小                    |

### 保护器件

|   器件   |       型号       |  厂商  |     功能    | 设计考量                                       |
| :----: | :------------: | :--: | :-------: | :----------------------------------------- |
|  过流保护  | **SY6280AAAC** |  矽力杰 | TSOT-23-5 | 1A 精密限流，响应速度 <2μs，防止短路烧毁主机 USB 端口          |
| TVS 阵列 |  **SMBJ5.0CA** | 君耀电子 |    SMB    | 5V 双向钳位，IPP 58.3A，吸收 ESD/浪涌能量，保护主控与 USB 设备 |

> **为什么需要两级保护？**
>
> - **SY6280（过流）**：应对 USB 设备短路、大电流充电等 **持续异常**，软件可恢复
> - **SMBJ5.0CA（过压）**：应对热插拔浪涌、静电放电等 **瞬态异常**，纳秒级响应
> - 两者互补，构成完整的 USB 端口保护体系

## 📐 设计要点

### 1. USB3.0 高速差分信号

- **差分阻抗控制**：USB3.0 SSTX/SSRX 差分对需控制 **90Ω ±10%** 特性阻抗
- **等长匹配**：同一对差分线长度差 ≤ 0.5mm，对间长度差 ≤ 5mm
- **参考平面**：高速信号下方保持完整的地平面，避免跨分割

### 2. 电源完整性

- **去耦电容**：每路电源轨就近放置 100nF + 10μF 组合去耦，0402 封装降低 ESL
- **DC-DC 布局**：电感与主控芯片间距 < 5mm，SW 节点走线短而粗，降低 EMI
- **5V 供电**：USB 端口 5V 走线线宽 ≥ 20mil，满足 2A 载流需求

### 3. 晶振电路

- 24/25MHz 晶振紧邻主控 XI/XO 引脚，负载电容 16pF/20pF 精确匹配晶振规格
- 晶振下方禁止走线，周围包地处理，减少噪声耦合

## 🛠️ 焊接与调试建议

1. **焊接顺序**：先焊主控芯片（QFN）→ 再焊小型阻容（0402）→ 最后焊 USB 接口与电感
2. **QFN 焊接技巧**：
   - 风枪温度 320°C，风速 3~4 档
   - 先在焊盘涂少量焊膏，对准标记后加热
   - 用镊子轻压芯片，观察回流情况
3. **上电检查**：
   - 万用表测量 5V / 3.3V / 1.2V 电源轨是否正常
   - 示波器检查晶振是否起振（24/25MHz 正弦波，幅度 > 0.5Vpp）
4. **功能验证**：
   - 连接电脑，设备管理器应识别为 "Generic SuperSpeed USB Hub"
   - 插 U 盘进行读写速度测试（USB3.0 应达到 100MB/s+）
